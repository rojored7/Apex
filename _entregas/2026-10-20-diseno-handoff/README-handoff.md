# APEX — entrega de diseño para Claude Code

Cómo usar esta carpeta:

1. Copia la carpeta `docs/design/` a la raíz del repositorio de APEX (queda `repo/docs/design/`).
2. Copia `docs/design/assets/logo/*.png` también a `frontend/public/brand/` cuando exista el proyecto de React.
3. Pega el contenido de `CLAUDE-md-fragmento.md` en el `CLAUDE.md` de la raíz del repo.
4. Abre Claude Code en el repo y pídele, por ejemplo: "Construye el layout del panel y la pantalla /socios siguiendo docs/design".

Contenido de docs/design: DESIGN.md (guía), ROUTES.md (rutas, roles y endpoints), SCREENS-INDEX.md (índice), screens/ (37 pantallas en claro y oscuro), prototipo.html (todo navegable), tokens.css y tokens.json, assets/logo/.
